  php artisan doctrine:migrations:migrate first --no-interaction

  これで一旦マイグレーション0件の状態（全テーブル未作成）まで巻き戻し、その後：

  php artisan doctrine:migrations:migrate --no-interaction

  で1〜5番のマイグレーションを最初から実行し直します。ただし、この方法は巻き戻し時にdown()が正しく
  書かれている前提で、かつ既存の全データが消えます。

  特定のマイグレーションだけをやり直したい場合

  Doctrineマイグレーションは基本的に「順番に適用していく」設計なので、途中の1本だけを差し替えて再
  実行する標準的な方法はありません。もし2番のマイグレーションだけをやり直したいなら、以下の手順に
  なります。

  1.
  マイグレーション履歴テーブル（doctrine_migration_versions）から、2番以降のバージョン記録を削除
  2. t_doctorsを含む、2番以降で作られたテーブルを手動でDROP
  3. 2番のファイルを修正
  4. php artisan doctrine:migrations:migrateで再実行

⏺ RecordはTypeScriptの組み込みユーティリティ型で、「特定のキーの集合」と「値の型」を指定してオブジェクト型を作るためのものです。Button.tsxの実例で解説します。

  該当コードの再確認

  type Variant = 'primary' | 'secondary' | 'danger'

  const variantClasses: Record<Variant, string> = {
    primary: 'bg-slate-900 text-white hover:bg-slate-700',
    secondary: 'bg-white text-slate-700 border border-slate-300 hover:bg-slate-50',
    danger: 'bg-white text-red-600 border border-red-200 hover:bg-red-50',
  }

  Record<K, V>の基本

  Record<K, V>は「キーの型がK、値の型がVであるオブジェクト型」を意味します。

  Record<Variant, string>

  これは以下の型を書いたのと全く同じ意味になります。

  {
    primary: string
    secondary: string
    danger: string
  }

  Variantが'primary' | 'secondary' | 'danger'というユニオン型（前回説明した「リテラル型のユニオン」）なので、Record<Variant, string>は「primary, secondary,
  dangerという3つのキーを必ず全部持ち、それぞれの値がstring型である」というオブジェクトの型になります。

  なぜこう書くと便利か

  1. キーの網羅性がコンパイル時にチェックされる

  もしvariantClassesの中身からdangerを書き忘れたとします。

  const variantClasses: Record<Variant, string> = {
    primary: 'bg-slate-900 text-white hover:bg-slate-700',
    secondary: 'bg-white text-slate-700 border border-slate-300 hover:bg-slate-50',
    // dangerを書き忘れた
  }

  この場合、TypeScriptはコンパイルエラーを出します。「Variant型は3つの値を持つはずなのに、dangerのプロパティが足りない」と教えてくれます。これにより、Variant（Button.
  tsx側のtype Variant = 'primary' | 'secondary' | 'danger'）に新しい種類（例えば'warning'）を追加した際、対応するvariantClassesの定義を書き忘れることを防げます。

  2. 存在しないキーへのアクセスも防げる

  variantClasses['success']  // エラー：'success'はVariant型に存在しないキー

  もしsuccessのようなタイプミスや、まだVariantに追加していないキーでアクセスしようとすると、これもコンパイル時に検知されます。

  実際の使われ方（Button.tsx内）

  export function Button({
    variant = 'primary',
    className = '',
    ...props
  }: Props) {
    return (
      <button
        className={`... ${variantClasses[variant]} ${className}`}
        {...props}
      />
    )
  }

  variantClasses[variant]で、渡されたvariant（'primary', 'secondary',
  'danger'のいずれか）に対応するTailwindクラス文字列を取り出しています。variantの型がVariantで、variantClassesの型がRecord<Variant,
  string>なので、TypeScriptは「variantClasses[variant]は必ずstring型の値が返ってくる」と保証できます（undefinedになる可能性を考慮する必要がない）。

  Recordを使わずに書いた場合との比較

  もしRecordを使わず、単純なオブジェクトリテラルの型推論に任せた場合：

  // Recordを使わない場合
  const variantClasses = {
    primary: 'bg-slate-900 text-white hover:bg-slate-700',
    secondary: 'bg-white text-slate-700 border border-slate-300 hover:bg-slate-50',
    danger: 'bg-white text-red-600 border border-red-200 hover:bg-red-50',
  }

  この書き方でも一見動きますが、「Variant型とvariantClassesのキーが一致しているか」をTypeScriptが積極的にチェックしてくれません。例えばVariantに'warning'を追加しても
  、variantClasses側を更新し忘れてもエラーになりません（variantClasses['warning']にアクセスした瞬間にundefinedが返り、実行時までバグに気づけない）。

  Record<Variant, string>と明示することで、「Variantの全パターンに対応する値を用意する」という制約をコンパイル時に強制できるのが最大のメリットです。

  Recordの一般的な用途

  Button.tsxのような「列挙値→対応する値のマッピング」以外にも、以下のような場面でよく使われます。

  // APIレスポンスのエラーメッセージ集約（前回のuseDepartments.tsで実際に使用）
  type FieldErrors = Record<string, string[]>

  これはuseDepartments.tsにも登場していました。string（任意のフィールド名、例:
  departments.0.name）をキーに、string[]（そのフィールドのエラーメッセージ配列）を値に持つオブジェクト、という意味です。この場合キーがVariantのような限定されたリテラ
  ル型ではなくstring（任意の文字列）なので、「どんなキーでもよいが、値の型は必ずstring[]」という緩やかな制約になります。

  まとめ

  ┌──────────────────────────┬──────────────────────────────────────────────────────────────────────────┐
  │          書き方          │                                   意味                                   │
  ├──────────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ Record<Variant, string>  │ キーは'primary' | 'secondary' | 'danger'のいずれかに限定、値は必ずstring │
  ├──────────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ Record<string, string[]> │ キーは任意の文字列、値は必ずstring[]                                     │
  └──────────────────────────┴──────────────────────────────────────────────────────────────────────────┘

  Record<K, V>は「オブジェクトのキーと値の型を一括で指定する」ためのユーティリティ型で、特に今回のようにユニオン型をキーにする場合、コンパイル時の網羅性チェックという
  強力なメリットを得られます。

  ┌──────┬───────────────────────────────────────────────────────────────────────────────┐
  │ 文字 │                                意味合いの慣習                                 │
  ├──────┼───────────────────────────────────────────────────────────────────────────────┤
  │ T    │ Type の頭文字。「何でもいい型」の代表格                                       │
  ├──────┼───────────────────────────────────────────────────────────────────────────────┤
  │ K    │ Key。オブジェクトのキーを表す型変数によく使う（今回のupdateFormはまさにこれ） │
  ├──────┼───────────────────────────────────────────────────────────────────────────────┤
  │ V    │ Value。キーに対応する値の型                                                   │
  ├──────┼───────────────────────────────────────────────────────────────────────────────┤
  │ E    │ Element。配列や集合の要素の型                                                 │
  ├──────┼───────────────────────────────────────────────────────────────────────────────┤
  │ U    │ 2つ目の型変数が必要なとき（Tの次のアルファベット）                            │
  ├──────┼───────────────────────────────────────────────────────────────────────────────┤
  │ R    │ Return。関数の戻り値の型                                                      │
  ├──────┼───────────────────────────────────────────────────────────────────────────────┤
  │ P    │ Props（React関連でよく見る）                                                  │
  └──────┴───────────────────────────────────────────────────────────────────────────────┘

        private PlanVehicleListUseCase $plan_vehicle_list_use_case,
        private PlanEquipmentListUseCase $plan_equipment_list_use_case,

    public function execute(string $plan_date): array
    {
        $plan_teams = $this->plan_team_repository->findAllByPlanDate($plan_date);
        $plan_team_ids = array_map(fn (PlanTeam $plan_team) => $plan_team->getId(), $plan_teams);

        $plan_vehicles = $this->plan_vehicle_list_use_case->execute($plan_team_ids);
        $plan_equipments = $this->plan_equipment_list_use_case->execute($plan_team_ids);
        $doctor_assignments = $this->doctor_assignment_list_use_case->execute($plan_team_ids);

        return array_map(
            fn (PlanTeam $plan_team) => [
                'id' => $plan_team->getId(),
                'plan_date' => $plan_team->getPlanDate(),
                'team_id' => $plan_team->getTeamId(),
                'team_name' => $plan_team->getTeamName(),
                'depart_time' => $plan_team->getDepartTime(),
                'arrive_time' => $plan_team->getArriveTime(),
                'sort_order' => $plan_team->getSortOrder(),
                'vehicles' => array_values(array_filter(
                    $plan_vehicles,
                    fn (array $row) => $row['plan_team_id'] === $plan_team->getId(),
                )),
                'equipments' => array_values(array_filter(
                    $plan_equipments,

                'doctor_assignments' => array_values(array_filter(
                    $doctor_assignments,

import { useEffect, useState } from 'react'
import axios from '@/lib/axios'
import type { Team, Vehicle } from '@/types/settings'
import type { TeamAssignment } from '@/types/monthlyPlan'
import {
  TEAM_CODE_DOCK,
  TEAM_CODE_INDUSTRIAL,
  VEHICLE_CODE_CENTER_INTERNAL,
} from '@/types/monthlyPlan'

type PlanVehicleRow = {
  id: number
  plan_team_id: number
  vehicle_id: number
  vehicle_name: string
}

type PlanEquipmentRow = {
  id: number
  plan_team_id: number
  equipment_id: number
  equipment_name: string
}

type DoctorAssignmentRow = {
  id: number
  plan_team_id: number
  doctor_id: number
  type: number
  has_am: boolean
  has_pm: boolean
}

type PlanTeamDetailRow = {
  id: number
  plan_date: string
  team_id: number
  team_name: string
  depart_time: string
  arrive_time: string
  sort_order: number
  vehicles: PlanVehicleRow[]
  equipments: PlanEquipmentRow[]
  doctor_assignments: DoctorAssignmentRow[]
}

export class PlanTeamNotSavedError extends Error {}

let local_id_sequence = -1

function findTeamByCode(teams: Team[], code: string): Team | undefined {
  return teams.find((team) => team.code === code)
}

function findCenterInternalVehicleIds(vehicles: Vehicle[]): number[] {
  return vehicles
    .filter((vehicle) => vehicle.code === VEHICLE_CODE_CENTER_INTERNAL)
    .map((vehicle) => vehicle.id)
    .filter((id): id is number => id !== null)
}

function createFixedAssignment(
  team: Team | undefined,
  departure_time: string,
  arrival_time: string,
  center_internal_vehicle_ids: number[],
): TeamAssignment {
  return {
    local_id: local_id_sequence--,
    plan_team_id: null,
    team_id: team?.id ?? null,
    team_code: team?.code ?? null,
    departure_time,
    arrival_time,
    vehicle_ids: center_internal_vehicle_ids,
    equipment_ids: [],
    am_doctor_ids: [],
    pm_doctor_ids: [],
  }
}

function createEmptyAssignment(): TeamAssignment {
  return {
    local_id: local_id_sequence--,
    plan_team_id: null,
    team_id: null,
    team_code: null,
    departure_time: '',
    arrival_time: '',
    vehicle_ids: [],
    equipment_ids: [],
    am_doctor_ids: [],
    pm_doctor_ids: [],
  }
}

export function useTeamAssignments(plan_date: string | null, teams: Team[], vehicles: Vehicle[]) {
  const [assignments, setAssignments] = useState<TeamAssignment[]>([])
  const [is_loading, setIsLoading] = useState(false)

  useEffect(() => {
    if (plan_date === null) {
      setAssignments([])
      return
    }

    let is_current = true

    async function load() {
      setIsLoading(true)

      try {
        const plan_teams_response = await axios.get<{ data: PlanTeamDetailRow[] }>(
          '/api/monthly-plan/plan-teams/detail',
          { params: { plan_date } },
        )
        const plan_teams = plan_teams_response.data.data

        if (!is_current) {
          return
        }

        function toAssignment(plan_team: PlanTeamDetailRow): TeamAssignment {
          const team = teams.find((row) => row.id === plan_team.team_id)

          return {
            local_id: local_id_sequence--,
            plan_team_id: plan_team.id,
            team_id: plan_team.team_id,
            team_code: team?.code ?? null,
            departure_time: plan_team.depart_time,
            arrival_time: plan_team.arrive_time,
            vehicle_ids: plan_team.vehicles.map((row) => row.vehicle_id),
            equipment_ids: plan_team.equipments.map((row) => row.equipment_id),
            am_doctor_ids: plan_team.doctor_assignments
              .filter((row) => row.has_am)
              .map((row) => row.doctor_id),
            pm_doctor_ids: plan_team.doctor_assignments
              .filter((row) => row.has_pm)
              .map((row) => row.doctor_id),
          }
        }

        const center_internal_vehicle_ids = findCenterInternalVehicleIds(vehicles)
        const industrial_team = findTeamByCode(teams, TEAM_CODE_INDUSTRIAL)
        const dock_team = findTeamByCode(teams, TEAM_CODE_DOCK)
        const industrial_plan_team = plan_teams.find((row) => row.team_id === industrial_team?.id)
        const dock_plan_team = plan_teams.find((row) => row.team_id === dock_team?.id)

        const industrial_assignment = industrial_plan_team
          ? toAssignment(industrial_plan_team)
          : createFixedAssignment(industrial_team, '07:45', '15:00', center_internal_vehicle_ids)
        const dock_assignment = dock_plan_team
          ? toAssignment(dock_plan_team)
          : createFixedAssignment(dock_team, '08:00', '15:00', center_internal_vehicle_ids)

        const other_assignments = plan_teams
          .filter((row) => row.id !== industrial_plan_team?.id && row.id !== dock_plan_team?.id)
          .sort((a, b) => a.sort_order - b.sort_order)
          .map(toAssignment)

        setAssignments([industrial_assignment, dock_assignment, ...other_assignments])
      } finally {
        if (is_current) {
          setIsLoading(false)
        }
      }
    }

    load()

    return () => {
      is_current = false
    }
    // plan_dateが変わった時だけ再読込する（teams/vehiclesの参照変化では再読込しない）
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [plan_date])

  function addAssignment() {
    setAssignments((prev) => [...prev, createEmptyAssignment()])
  }

  function removeAssignment(local_id: number) {
    setAssignments((prev) => prev.filter((row) => row.local_id !== local_id))
  }

  function updateAssignment<K extends keyof TeamAssignment>(
    local_id: number,
    field: K,
    value: TeamAssignment[K],
  ) {
    setAssignments((prev) =>
      prev.map((row) => (row.local_id === local_id ? { ...row, [field]: value } : row)),
    )
  }

  function toggleVehicle(local_id: number, vehicle_id: number) {
    setAssignments((prev) =>
      prev.map((row) => {
        if (row.local_id !== local_id) {
          return row
        }
        const has = row.vehicle_ids.includes(vehicle_id)
        return {
          ...row,
          vehicle_ids: has
            ? row.vehicle_ids.filter((id) => id !== vehicle_id)
            : [...row.vehicle_ids, vehicle_id],
        }
      }),
    )
  }

  function toggleEquipment(local_id: number, equipment_id: number) {
    setAssignments((prev) =>
      prev.map((row) => {
        if (row.local_id !== local_id) {
          return row
        }
        const has = row.equipment_ids.includes(equipment_id)
        return {
          ...row,
          equipment_ids: has
            ? row.equipment_ids.filter((id) => id !== equipment_id)
            : [...row.equipment_ids, equipment_id],
        }
      }),
    )
  }

  function updateDoctorAssignment(local_id: number, am_doctor_ids: number[], pm_doctor_ids: number[]) {
    setAssignments((prev) =>
      prev.map((row) =>
        row.local_id === local_id ? { ...row, am_doctor_ids, pm_doctor_ids } : row,
      ),
    )
  }

  function copyAssignment(local_id: number) {
    setAssignments((prev) => {
      const target = prev.find((row) => row.local_id === local_id)
      if (target === undefined) {
        return prev
      }
      const copied: TeamAssignment = {
        ...target,
        local_id: local_id_sequence--,
        plan_team_id: null,
        team_id: null,
        team_code: null,
      }
      return [...prev, copied]
    })
  }

  async function saveAssignment(local_id: number) {
    const target = assignments.find((row) => row.local_id === local_id)
    if (target === undefined || target.team_id === null || plan_date === null) {
      return
    }

    let plan_team_id = target.plan_team_id

    if (plan_team_id === null) {
      const response = await axios.post<{ data: { id: number } }>('/api/monthly-plan/plan-teams/save', {
        plan_date,
        team_id: target.team_id,
        depart_time: target.departure_time,
        arrive_time: target.arrival_time,
      })
      plan_team_id = response.data.data.id
    } else {
      await axios.put(`/api/monthly-plan/plan-teams/${plan_team_id}`, {
        team_id: target.team_id,
        depart_time: target.departure_time,
        arrive_time: target.arrival_time,
      })
    }

    await Promise.all([
      axios.put(`/api/monthly-plan/plan-vehicles/${plan_team_id}`, {
        vehicle_ids: target.vehicle_ids,
      }),
      axios.put(`/api/monthly-plan/plan-equipments/${plan_team_id}`, {
        equipment_ids: target.equipment_ids,
      }),
      axios.put(`/api/monthly-plan/doctor-assignments/${plan_team_id}`, {
        am_doctor_ids: target.am_doctor_ids,
        pm_doctor_ids: target.pm_doctor_ids,
      }),
    ])

    setAssignments((prev) =>
      prev.map((row) => (row.local_id === local_id ? { ...row, plan_team_id } : row)),
    )
  }

  async function saveDoctorAssignment(local_id: number) {
    const target = assignments.find((row) => row.local_id === local_id)
    if (target === undefined) {
      return
    }

    if (target.plan_team_id === null) {
      throw new PlanTeamNotSavedError()
    }

    await axios.put(`/api/monthly-plan/doctor-assignments/${target.plan_team_id}`, {
      am_doctor_ids: target.am_doctor_ids,
      pm_doctor_ids: target.pm_doctor_ids,
    })
  }

  return {
    assignments,
    is_loading,
    addAssignment,
    removeAssignment,
    updateAssignment,
    toggleVehicle,
    toggleEquipment,
    updateDoctorAssignment,
    copyAssignment,
    saveAssignment,
    saveDoctorAssignment,
  }
}
